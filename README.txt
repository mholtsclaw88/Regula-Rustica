REGULA RUSTICA v4.0

Netlify deployment:
1. Drag this entire regula-rustica-v4 folder into Netlify Drop.
2. Use the same Netlify site as v3 if you want the same browser storage to remain available.
3. Open the site on your phone and install/add it to the home screen.

V4 additions:
- All Tasks view with status, record, due-date and sorting controls
- Monthly calendar and 30-day agenda using existing task due dates
- User-created workflow templates in Settings
- Templates can be applied when creating matching records

Data remains local to each browser/device. Download backups regularly.
