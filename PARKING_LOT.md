# Regula Rustica Parking Lot

## Purpose

This document captures worthwhile ideas that are intentionally deferred. It exists to protect current work from unnecessary scope while ensuring useful ideas are not lost.

An item belongs here when it is plausible but not yet justified by real use, not required for current reliability, and not already part of the Roadmap.

## Tasks and Daily Work

- Task watchers or secondary observers
- Child kiosk mode for viewing assigned work and completing permitted Tasks
- Advanced recurring Task exceptions
- Seasonal recurrence rules beyond current practical needs
- Reminder and notification system
- More advanced Chore Window exceptions
- Drag-and-drop planning only if ordinary scheduling proves inadequate

## Records

- Custom Record types
- User-defined custom fields
- Inventory as a first-class domain
- Production batches as a first-class domain
- Additional specialized Record relationships

## Specialized Stewardship

These should not become separate mini-applications unless the universal Record/Task/Journal/Yield/Ledger model proves insufficient:

- Rotational grazing tools
- Orchard management
- Beekeeping-specific management
- Maple syrup management
- Forestry planning
- Cheese-aging inventory
- Weather-aware planning

## AI — The Cellarer

- Natural-language Homestead lookup
- Voice-first data entry
- Photo identification
- Seasonal recommendations
- AI-assisted summaries and reporting
- Maintenance suggestions from equipment history

AI remains subordinate to Regula Rustica as the system of record.

## Reporting

- Financial reports beyond the working Ledger
- Production and Yield trends
- Stewardship summaries
- Additional export/report formats
- Optional dashboards where they answer a real management question

## Mobile and Device Experience

- Push notifications
- Background photo uploads
- Deeper device/offline diagnostics if ordinary recovery tools prove insufficient

## Explicitly Not Planned Without Strong Evidence

- Generic enterprise workflow builders
- Complex custom permission matrices
- Social/community features
- Gamification
- Office-style hourly Task scheduling
- Public Homestead directory
- A separate mini-app for every species or agricultural activity

## Guiding Rule

A feature should move from the Parking Lot into the Roadmap only when it clearly supports the Constitution, fits the Design Language and stewardship model, solves a problem observed through real use, and justifies its maintenance cost.
